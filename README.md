# Employee Time Tracker API

REST API desarrollada con Spring Boot para gestionar:

- Clock In
- Clock Out
- Breaks
- Empleados
- Jornadas laborales

## Tecnologías

- Java 21+
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Lombok
- Maven

## Funcionalidades

- CRUD de empleados
- Registro de entrada y salida
- Registro de breaks
- Validaciones de negocio
- Manejo de excepciones
- Arquitectura por capas
